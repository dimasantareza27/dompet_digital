# Sistem Keuangan Mahasiswa

Aplikasi web manajemen keuangan pribadi untuk mahasiswa. Dibangun dengan PHP Native + MySQL.

## Tech Stack
- **Frontend:** HTML5, CSS3 (tanpa framework)
- **Backend:** PHP 8.x Native (prosedural)
- **Database:** MySQL(mysqli)

## Setup
1. Clone repo ini
2. Taruh di folder `htdocs` / `www` (Laragon/XAMPP)
3. Import `schema.sql` ke MySQL
4. Akses di browser: `http://localhost/Sistem_Keuangan_Mahasiswa/`
